# Let's Talk at School! (อ32202 ม.5)
โรงเรียนศรีเจริญศึกษา | ผู้สอน นายธวัฒน์ สารรัตน์

## ภายในไฟล์
- `index.html` เว็บไซต์ Responsive รองรับหน้าจอคอมพิวเตอร์ Android และ iOS
- `assets/` ภาพจากใบความรู้ที่ 2 ที่ผู้ใช้ให้มา (ครอปเป็นภาพประกอบ)
- `config.js` ค่าการเชื่อมฐานข้อมูล Firebase และอีเมลผู้สอน
- `firestore.rules` กฎจำกัดการเข้าถึงข้อมูลนักเรียน
- `manifest.webmanifest` ข้อมูลเว็บแอปและไอคอนติดตั้งหน้าจอ

## วิธีทดลองเว็บไซต์ทันที
1. แตกไฟล์ ZIP เปิด `index.html` ด้วย Chrome, Edge หรือ Safari (แนะนำเปิดผ่านเว็บเซิร์ฟเวอร์เพื่อให้ทุกฟีเจอร์ทำงานครบ)
2. กดเริ่มเรียน กรอกชื่อ นามสกุล ชั้น/ห้อง และเลขที่
3. ฟังบทสนทนาและฝึกออกเสียงแต่ละประโยค กด `✓ ฝึกแล้ว` เพื่อบันทึกความก้าวหน้าหลังฝึก
4. ต้องเรียนให้ครบทั้ง 3 เรื่องจึงจะทำแบบทดสอบ 5 ข้อได้
5. **โหมดทดลอง** เก็บข้อมูลใน `localStorage` ของเครื่องนั้นเท่านั้น ไม่ใช่ฐานข้อมูลส่วนกลาง และครูยังไม่สามารถดูคะแนนนักเรียนทุกเครื่องได้

## เปิดใช้งานฐานข้อมูลออนไลน์ Firebase (จำเป็นสำหรับการใช้จริง)
1. ไปที่ https://console.firebase.google.com สร้างโปรเจ็กต์ และเพิ่ม Web App เพื่อรับ `firebaseConfig`
2. เปิด Authentication > Sign-in method เปิด **Anonymous** สำหรับนักเรียน และ **Email/Password** สำหรับครู
3. ที่ Authentication > Users สร้างบัญชีครูด้วยอีเมล/รหัสผ่าน และดำเนินการยืนยันอีเมลครูให้สำเร็จ (ต้องมี `email_verified=true`)
4. เปิด Firestore Database แล้วสร้างฐานข้อมูล (เลือก region ตามเหมาะสม)
5. ที่ `config.js` แทนค่า `REPLACE_...` ด้วยค่าจริงจาก Firebase และเปลี่ยน `teacherEmail` เป็นอีเมลครู
6. ที่ `firestore.rules` เปลี่ยน `teacher@example.com` ให้ตรงกับอีเมลครู จากนั้นคัดลอกกฎไปที่ Firestore > Rules แล้วกด Publish
7. เพิ่ม authorized domain ของเว็บใน Firebase Authentication > Settings > Authorized domains หากจำเป็น
8. อัปโหลดไฟล์ทั้งหมดไป GitHub repo และเปิด Settings > Pages > Deploy from a branch > main / (root)
9. เปิด URL GitHub Pages ตรวจการแสดงสถานะ `🟢 ฐานข้อมูลออนไลน์`, สร้างข้อมูลทดสอบ, ทำบทเรียนและส่งคะแนน, จากนั้นเข้าสู่ระบบครูเพื่อดูข้อมูลและส่งออก CSV

**สำคัญ:** ชื่อ–นามสกุลที่กรอกเป็นข้อมูลระบุตัวตน ไม่ใช่การยืนยันตัวตนทางราชการ นักเรียนในระบบนี้ใช้ Firebase Anonymous Auth ซึ่งผูกกับบัญชีในเบราว์เซอร์ หากเปลี่ยนเครื่องหรือล้างข้อมูล อาจเข้าเป็นคนละบัญชีและข้อมูลไม่ต่อเนื่อง ก่อนใช้จริงควรพัฒนาเป็นระบบล็อกอินนักเรียน (เช่นรหัสนักเรียนพร้อมการยืนยันตัวตน หรือ Google Sign-in ที่อนุญาต) และกำหนดนโยบายคุ้มครองข้อมูลส่วนบุคคลให้เหมาะสม

**ความปลอดภัยด้านคะแนน:** ตัวอย่างนี้คำนวณคะแนนบนฝั่งเบราว์เซอร์และส่งคะแนนไป Firestore กฎป้องกันนักเรียนอ่านข้อมูลผู้อื่นและแก้คะแนนหลังบันทึก แต่ **ไม่ป้องกันนักเรียนแก้คะแนนก่อนส่งด้วยเครื่องมือพัฒนาเว็บ** หากใช้เป็นคะแนนทางการ จำเป็นต้องย้ายการตรวจคำตอบและบันทึกคะแนนไป Cloud Functions หรือเซิร์ฟเวอร์ที่เชื่อถือได้

## หมายเหตุเสียงและวิดีโอ
- ปุ่ม `▶ เล่นบทสนทนาต่อเนื่อง` แสดงฉากและบทพูดทีละประโยคพร้อมเสียงสังเคราะห์ภาษาอังกฤษจากระบบของอุปกรณ์ ถือเป็นสื่อบทสนทนาเชิงโต้ตอบ **ไม่ใช่ไฟล์วิดีโอ MP4 ที่ถ่ายทำ/เรนเดอร์แล้ว**
- หากต้องการคลิปวิดีโอแอนิเมชันจริง ให้ผลิตคลิปทั้ง 3 ตอนและเชื่อมเข้ากับหน้าเว็บเพิ่มเติม
- ปุ่มพูดใช้ Web Speech Recognition ที่ความเข้ากันได้แตกต่างกันตามอุปกรณ์/เบราว์เซอร์ เมื่อไม่รองรับ ให้ฝึกด้วยการฟังและใช้ปุ่ม `✓ ฝึกแล้ว` แทน; การตรวจพบเสียงยังไม่ใช่การให้คะแนนความถูกต้องการออกเสียง
- เสียงสังเคราะห์อาจต่างกันตามเสียงที่ติดตั้งบนเครื่อง และต้องเปิดเสียง/กดเล่นโดยผู้ใช้งานเองบนบาง iPhone
